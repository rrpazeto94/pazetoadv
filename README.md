# Rafael Raasch Pazeto — Advocacia

## Arquivos atualizados
- `index.html`
- `css/styles.css`
- `js/main.js`
- `js/animations.js`

## Como aplicar no projeto existente
1. Faça uma cópia de segurança da versão atual.
2. Extraia estes arquivos sobre a pasta principal do projeto, mantendo a estrutura de pastas.
3. **Mantenha a pasta `assets/` original**, pois ela contém favicon, ícones e imagens já referenciados pelo site.
4. Abra `index.html` e teste os links de navegação e os botões de WhatsApp.

## O que foi alterado
- Removido o painel ilustrativo de revisão de contratos que aparecia na primeira dobra.
- Hero reorganizado em largura ampla, com links diretos para as três áreas.
- Posicionamento e textos revisados para Direito Digital, LGPD e Juizado Especial Cível.
- Atualizados situações selecionáveis, perfis de atendimento, perguntas frequentes e opções do formulário.
- Ajustado o layout dos três cards e removidas as interações/animações exclusivas do painel antigo.

## Configuração antes de publicar
Edite `CONFIG` no início de `js/main.js` para informar seu WhatsApp (DDI + DDD + número) e OAB/ES. O WhatsApp vazio abre a tela de escolha de contato.
